# Roadmap

这是一个研究交流版路线图，不承诺时间表，欢迎通过 issue 讨论优先级。

## Near Term

- 增加更完整的本地安装说明和故障排查。
- 给 SQLite schema 增加版本化迁移脚本。
- 加入更清晰的示例数据或 mock 数据，方便无 Tushare token 的用户体验页面。
- 为 AI PK 增加更多 benchmark，例如沪深300、中证500、创业板 ETF 组合。
- 将研报质量评分输出成独立看板。

## Analysis Quality

- 扩展 14 类操作手法的回测样本。
- 给每类手法增加失败案例和反例库。
- 引入更严格的策略评估指标：最大回撤、夏普、换手率、交易成本、命中滞后。
- 对研报作者/团队做跨行业和跨周期评分。

## Data Layer

- 增强 Tushare、AKShare、Baostock 的字段映射说明。
- 增加数据质量审计：缺失率、延迟、异常值、复权一致性。
- 支持更细粒度的数据蒸馏，减少硬盘占用。

## Product

- 改进持仓变动录入和截图识别流程。
- 增加导入/导出研究笔记。
- 给 AI PK 裁判规则增加可视化审计。
- 给用户互动股票添加长期跟踪和提醒策略配置。

## Community

- 收集更多真实使用者对分析流程的反馈。
- 讨论哪些模块应该拆成独立包。
- 整理可公开的策略评估样例。
