# Architecture

系统按“数据 -> 分析 -> 决策 -> 行动 -> 反馈”闭环组织。

## 数据层

- Tushare：行情、财务、资金流、研报等高价值结构化数据。
- AKShare / Baostock：补充行情和公开数据。
- SQLite：本地缓存和运行态记录。公开仓库不包含真实数据库。

## 分析层

- 单股分析：行情、资金、财务、研报、手法识别和多 AI 观点。
- 14 类操作手法：把市场行为拆成可检测的规则标签。
- 研报质量层：按券商、作者、团队进行观点抽取和命中率反测。

## 决策层

- 多 AI 分工：不同模型看不同风险面和风格面。
- AI PK：模拟真实 A 股交易约束，包括 100 股一手、T+1、佣金、印花税、涨跌停和流动性冲击。
- IndexETF 基准：用指数基金组合作为被动参照。
- Referee 裁判：记录交易时间、交易理由和规则审计。

## 反馈层

- 用户互动股票持续跟踪。
- 持仓变动导入。
- 推荐来源记忆。
- 历史分析反测与胜率更新。
